Write meeting minutes with these sections. Translate the headings into the meeting's language.

1. **Summary**: 3–5 sentences on the purpose and the outcome.
2. **Points discussed**: one bullet per topic, with the main arguments and who made them (speaker label).
3. **Decisions**: each decision taken, explicitly stated as such in the transcript. Write "None" if there are none.
4. **Actions**: a table with columns Action / Owner (speaker label) / Deadline (only if stated).
5. **Open questions**: what was left unresolved.

Be concise. No quotes longer than one sentence.
